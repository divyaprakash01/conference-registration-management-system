# Conference Registration Management System

A web-based **no-code conference registration form builder** that enables organizers to create, customize, and export registration forms through an interactive interface.

## Overview

The application is designed to reduce repetitive effort when creating conference registration forms. Users can build forms visually using reusable components, configure logical dependencies between fields, and export the completed form as a standalone HTML page.

## Key Features

- Drag-and-drop form building
- Text, single-select, multi-select, and informational components
- Interactive editing of form elements
- Logical dependencies between questions
- Dynamic form resizing
- Export of completed forms as HTML
- Dark mode support
- Example registration form
- Responsive web interface

## Tech Stack

- **HTML5** — page structure
- **CSS3** — styling and responsive layout
- **JavaScript** — UI interactions, form logic, dependencies, and export functionality
- **Figma** — wireframe and interface design
- **Git/GitHub** — version control and collaboration

## Run Locally

Clone the repository:

```bash
git clone https://github.com/divyaprakash01/conference-registration-management-system.git
cd conference-registration-management-system
```

Open the main webpage from:

```text
code/webpage/
```

The application can be opened directly in a modern browser; no backend server is required.

## Usage

1. Add form components using the builder interface.
2. Arrange and resize components in the workspace.
3. Edit questions, options, and logical dependencies.
4. Preview the registration form.
5. Export the completed form as an HTML file.
6. Open the exported form independently in a browser.
